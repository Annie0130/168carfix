# 階段 A 更新內容

## 部署前必做:更新資料庫
你的資料庫已經有 vehicles / reports 表了,這次只是**新增欄位**,不會刪除任何現有資料。

1. 到 Vercel → Storage → 你的資料庫 → Open in Neon → SQL Editor
2. 把 `migration-2.sql` 的內容整段貼上去執行一次
3. 確認沒有錯誤訊息

## 部署方式
跟之前一樣:把整包檔案(蓋掉舊的)透過 GitHub Desktop 上傳(Commit → Push),
Vercel 會自動重新部署,不需要改任何環境變數或設定。

## 這次新增了什麼

**店內後台建立報告時**
- 檢測項目狀態改成三色標籤(正常/建議留意/需立即更換),不再是下拉選單
- 電瓶健康度、四輪胎紋深度、前後煞車來令片厚度可以直接填數值,系統自動判斷燈號
  (門檻值先用業界常見標準,例如胎紋 < 1.6mm 標紅、來令片 < 3mm 標紅,之後可以再跟我說要怎麼調)
- 新增「本次維修/耗材明細」表格,可以填項目、數量、單價、保固,自動算小計和總計
- 新增「下次保養建議」,可以選 +5000km / +10000km / 自訂里程,還有建議日期
- 新增「待修/建議後續更換項目」標籤區,讓車主知道下次要準備換什麼
- 整體建議和備註欄位旁邊多了麥克風按鈕,可以用說的輸入文字(手機 Chrome / Android 支援較好,
  iPhone 的 Safari 目前對這個語音輸入的支援比較有限,不一定每台裝置都能用)

**報告頁面(客人看到的)**
- 關鍵零件狀態用進度條視覺化呈現(電瓶健康度、胎紋深度、來令片厚度)
- 檢測項目狀態改成彩色標籤
- 顯示本次維修明細表格與保固資訊
- 顯示下次保養建議
- 顯示待修建議項目
- 新增「分享到 LINE」按鈕,點一下可以直接把報告連結傳給任何人(不需要串接 LINE 官方帳號)
- 客人可以點「我同意此報價,同意施作」,系統會記錄同意時間

**掃 QR Code 看到的車輛頁面**
- 改成時間軸呈現,每筆報告會顯示當時換了哪些零件(標籤形式)
- 如果該次報告有「需立即更換」的項目,時間軸上會有紅點提醒
