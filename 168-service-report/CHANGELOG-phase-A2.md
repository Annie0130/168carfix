## 部署前必做:更新資料庫
1. Vercel → Storage → 你的資料庫 → Open in Neon → SQL Editor
2. 貼上 `migration-3.sql` 的內容執行(只新增欄位,不影響現有資料)
3. 確認沒有錯誤訊息

## 部署方式
跟之前一樣,GitHub Desktop 覆蓋檔案 → Commit → Push,Vercel 自動重新部署。

## 這次新增了什麼

**廠內即時看板(`/admin/board`,登入後台後從「車輛總覽」頁右上角進入)**
- 六個流程欄位:待檢測 → 檢查中 → 待客戶確認 → 待料中 → 施工中 → 完工待交車
- 每張卡片顯示車牌、車型、車主電話、負責技師、停留時間(自動每分鐘更新)
- 滑鼠可以直接拖曳卡片換欄位,也有「上一步/下一步」按鈕(比較適合觸控螢幕)
- 完工待交車的卡片有「交車完成」按鈕,按下去會從看板移除(回到後台可以重新開始下一次維修)
- 上方有搜尋(車牌末4碼/電話/姓名皆可)、技師篩選、當日交車/留車中篩選
- 每 45 秒自動整頁刷新一次資料,不需要手動重新整理

**車輛怎麼上看板**
- 之後每次在後台「新增車輛」,會自動進入「待檢測」欄位
- 現有的舊車輛不會自動出現在看板上,如果要讓某台舊車開始新一輪維修流程,
  到該車輛的後台頁面,會看到「開始新的維修流程」按鈕

**車輛詳細頁新增「目前維修進度」控制面板**
- 可以手動調整狀態、指派技師(目前技師名單只有「阿榮」,之後要加人跟我說)、
  預估完工取車時間、是否當日交車、是否留車中
- 這裡改的資料會跟看板同步

**客人端(掃 QR Code 進去的頁面)**
- 如果車輛目前有進行中的維修案件,頁面最上方會顯示進度條(入廠→健檢→報價→施工→完工)
  和目前狀態、負責技師、預估完工時間
- 頁面底部固定顯示快速操作列:「致電車廠」「導航取車」(直接開 Google 地圖導航到店裡)
